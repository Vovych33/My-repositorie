## Mermaid

Мармауд - это довольно упрощённый и далёкий аналог uml - спец. язык описания блок-схем, графиков и диаграмм с их визуализацией.

Блок схемы

```mermaid
flowchart LR
   A[Вопрос: как сделать список?] --> B[ответ: `-` или `*`]
   A --> C["пример: \n - Пункт 1 \n"]
```

* `Flowchart` - блок-схема
* `LR` - направление вправо
* `А[],В[],С[]` - прямоугольник
* `-->` - стрелка связи
самостоятельно

### Диаграмма последовательности
```mermaid
sequenceDiagram
    autonumber
    participant Пользователь
    participant Система
    participant БазаДанных
    
    Пользователь->>Система: Запрос на авторизацию
    Система->>БазаДанных: Проверка логина/пароля
    БазаДанных-->>Система: Данные подтверждены
    Система-->>Пользователь: Токен доступа
```

### Диаграмма класса

### Граф зависимостей
```mermaid
graph TD
    A[Главный модуль] --> B(Модуль авторизации)
    A --> C(Модуль базы данных)
    B --> D[Библиотека JWT]
    C --> E[Драйвер PostgreSQL]
    C --> F[ORM]
```
### Диаграмма состояний
```mermaid
stateDiagram-v2
    [*] --> Новый
    Новый --> В_работе: Взят в работу
    В_работе --> На_проверке: Код готов
    На_проверке --> В_работе: Есть замечания
```

### Кастомизация стилей
```mermaid
graph LR
    A[Старт] --> B[Процесс]
    B --> C[Конец]
    
    %% Инлайн-стили
    style A fill:#f9f,stroke:#333,stroke-width:2px,color:#fff
    style B fill:#bbf,stroke:#f66,stroke-width:2px,color:#fff,stroke-dasharray: 5 5
```
#### Классы CSS
```mermaid
graph TD
    A[Кнопка 1]:::red --> B[Кнопка 2]:::blue
    
    %% Определение классов

    classDef blue fill:#00f,stroke:#333,stroke-width:2px,color:#fff;
```
